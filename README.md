# mosaic

Mosaic is an independently developed LGBTQ+ news aggregator by XiaXia (ChaosXX™). Built by a marginalized creator, for the marginalized community — Mosaic exists because safe, accessible information can mean the difference between survival and persecution. In countries where being LGBTQ+ is criminalized, where censorship blocks vital resources, where seeking help can be dangerous, having the right information at the right time can save lives.
